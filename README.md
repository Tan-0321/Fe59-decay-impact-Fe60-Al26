# Fe59-decay-impact-Fe60-Al26
This repository is for the paper "The Impact of New Fe59 Decay Rates on Fe60 and Al26 Nucleosynthesis in Massive Stars" by Bingyang Tan. 

This repository includes the data for Table 2 (basic evolution properties) and Table 3 (isotopic yields) in CSV and MRT formats, along with the Jupyter Notebook used to calculate Galactic flux ratios and reproduce Figure 7.
